# Proyectos reproducibles con renv
📅 **Fecha**: 24 de junio de Julio de 2026

### **Oradora:** [Paola Corrales](https://paocorrales.github.io/). Doctora en Ciencias Atmosféricas por la Universidad de Buenos Aires. Actualmente, se desempeña como ingeniera de software de investigación en el Centro de Excelencia 21st Century Weather(Australia). 

**Breve descripción**

El taller abordó el uso de renv para gestionar la reproducibilidad de proyectos en R. Se explicó cómo las actualizaciones de paquetes externos (como ggplot2, data.table o knitr) pueden alterar los resultados de un análisis con el paso del tiempo. A partir de esto, se mostró cómo encapsular las dependencias de un proyecto,los paquetes utilizados y sus versiones, para poder recrear el entorno de trabajo en el futuro. El objetivo fue brindar herramientas prácticas para asegurar que un análisis pueda reproducirse de forma confiable.
